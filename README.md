# Практична робота №4 — Модульна структура TypeScript

## 📘 Опис роботи
У цій практичній роботі здійснено рефакторинг коду з попередньої практичної роботи №2.  
Увесь вихідний TypeScript-код було логічно розбито на модулі, типи винесено в окрему папку, а головний файл `main.ts` об’єднує всі модулі в єдину систему.

Проєкт повністю відповідає вимогам викладача та структурі ES-модулів.
